# Claude

Глобальная конфигурация Claude Code: агенты, скиллы, хуки.

## Установка

Скопируй файлы в глобальную папку Claude Code:

```powershell
# Агенты
Copy-Item claude\agents\*.md "$env:USERPROFILE\.claude\agents\"

# Скиллы
Copy-Item -Recurse claude\skills\* "$env:USERPROFILE\.claude\skills\"

# Хуки
Copy-Item claude\hooks\* "$env:USERPROFILE\.claude\hooks\"
```

Затем объедини `claude\settings.json` с `~/.claude/settings.json` вручную — добавь секцию `hooks` и нужные плагины.

## Агенты (`claude/agents/`)

Агенты — специализированные субагенты, которые Claude вызывает по контексту или по явному запросу (`@имя`).

| Агент | Назначение |
|---|---|
| `doc-specialist` | Чтение PDF/DOCX/XLSX, написание и редактирование технических документов, структурирование материала, формирование выходных файлов |
| `github-specialist` | Ежедневный push, создание PR и релизов, управление Issues, работа с ветками через `gh` CLI и `git`; самообучающийся — запоминает стиль commit messages и workflow |
| `powershell-specialist` | Написание, отладка и выполнение PowerShell скриптов; самообучающийся — запоминает предпочтения по стилю кода и удачные решения |
| `project-manager` | Инициализация нового проекта: создаёт README.md, .gitignore, doc/TODO.md, локальных агентов под тип задачи; управляет структурой папок по ходу проекта |
| `remote-ops-specialist` | Автоматизация удалённых Windows-машин через paramiko (SSH/SFTP) — выполнение команд, перенос файлов, надёжный запуск долгоживущих процессов, диагностика зависших процессов, очистка после экспериментов; самообучающийся — запоминает рабочие паттерны и грабли по машинам |

Каждый агент с пометкой «самообучающийся» читает и обновляет свой файл базы знаний (`*-knowledge.md`) после каждой сессии.

## Скиллы (`claude/skills/`)

Скиллы — встроенные команды, вызываемые через `/имя`.

| Скилл | Назначение |
|---|---|
| `adversarial-review` | Жёсткая критика плана, идеи или архитектуры с позиции скептика — только уязвимости, допущения и риски, без похвалы |
| `grill-me` | Глубокий структурированный допрос идеи перед стартом — вопросы по одному, в конце резюме + список неясностей + следующий шаг + создание CLAUDE.md |
| `runbook` | Диагностика проблем по симптомам — гипотезы, пошаговые проверки от простого к сложному, решение и профилактика |
| `scaffold` | Генерация структуры нового проекта — показывает дерево файлов, создаёт папки и базовые файлы с минимальным рабочим содержимым |
| `standup-post` | Сбор результатов рабочего дня из git log, изменённых файлов и заметок; формирует отчёт в формате стендапа |
| `project-structure` | Правила размещения файлов по папкам (src/, doc/, data/, results/, logs/, config/, tmp/); применяется автоматически при старте в пустой папке |

## Хуки (`claude/hooks/`)

### `agent-reminder.ps1`

Выполняется при каждом `UserPromptSubmit`. Читает список агентов из `~/.claude/agents/*.md` и выводит системное сообщение с подсказкой — кому делегировать задачу:

- PowerShell → `powershell-specialist`
- GitHub → `github-specialist`
- Документация → `doc-specialist`
- Новый проект → `project-manager`

### Хук пустой папки (в `claude/settings.json`)

Второй хук в `UserPromptSubmit`: если в текущей папке нет `.claude/` и нет файлов — выводит системное сообщение о том, что нужно использовать `project-manager` для инициализации проекта.

## Использование

```text
/grill-me            — проработать идею перед стартом
/adversarial-review  — найти слабые места в плане
/standup-post        — сформировать дневной отчёт
/runbook             — диагностировать проблему
/scaffold            — создать структуру нового проекта
/project-structure   — правила размещения файлов
```

Агенты вызываются автоматически по контексту или явно через `@имя`:
`@doc-specialist`, `@github-specialist`, `@powershell-specialist`, `@project-manager`, `@remote-ops-specialist`.
