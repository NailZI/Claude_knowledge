## Структура проекта

Папки создаются только когда в них помещается первый файл. Пустые папки не создавать никогда.

## Размещение файлов

| Тип файла | Папка |
|-----------|-------|
| Главный / запускающий файл | корень проекта |
| Исходные скрипты, модули, классы | src/ |
| Документация (кроме README.md) | doc/ |
| Входные данные | data/ |
| Результаты выполнения | results/ |
| Логи | logs/ |
| Конфигурация | config/ |
| Временные файлы отладки | tmp/ |

## Корень проекта содержит только
- `main.py` / `run.sh` / `app.py` — один запускающий файл
- `README.md`
- `.gitignore`
- `requirements.txt` (Python) или `install.sh` (bash)

## .gitignore всегда включает
```
tmp/
logs/
results/
__pycache__/
*.pyc
.env
```

## При старте нового проекта

1. Спроси у пользователя: тип проекта (Python / bash / GUI / смешанный) и название
2. Создай `README.md` с названием и кратким описанием
3. Создай `.gitignore` по шаблону выше
4. Больше ничего не создавай — папки появляются по мере файлов

## Правила для агента (применять всегда)

- Перед созданием файла определи его тип и выбери папку по таблице выше
- Если папки ещё нет — создай её вместе с файлом
- Никогда не создавай папку без файла внутри
- Если файл не подходит ни под одну категорию — спроси пользователя
