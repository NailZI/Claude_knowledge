# Shared

Здесь лежат знания и соглашения, которые не привязаны жёстко ни к Claude, ни к Codex.

Используй `shared/`, когда правило или материал:

- одинаково полезен в обеих средах;
- не зависит от конкретного формата skills/agents/hooks;
- лучше хранить один раз, чем дублировать в двух ветках знаний.

Текущий состав:

- `conventions.md` — переносимые рабочие соглашения высокого уровня.

В `shared/` не стоит класть:

- Claude hooks;
- Codex-only `AGENTS.md`;
- skills, завязанные на конкретный рантайм;
- файлы, которые требуют разной логики поведения в Claude и Codex.
