# Claude Knowledge

Глобальные скиллы и агенты для Claude Code.

## Скиллы (`skills/`)

| Скилл | Назначение |
|---|---|
| `grill-me` | Глубокий допрос идеи перед стартом — выявляет слепые пятна и формирует кристальное понимание задачи |
| `adversarial-review` | Жёсткая критика плана или архитектуры — ищет уязвимости, слабые допущения, риски |
| `standup-post` | Собирает что сделано за день из git log и файлов, формирует отчёт для стендапа |
| `runbook` | Диагностика проблем по симптомам — гипотезы, пошаговые проверки, решение + профилактика |
| `scaffold` | Генерирует структуру нового проекта — папки, базовые файлы, конфигурация |

## Агенты (`agents/`)

| Агент | Назначение |
|---|---|
| `doc-specialist` | Работа с документацией: чтение PDF/DOCX/XLSX, написание, редактирование, структурирование, проверка на полноту |
| `powershell-specialist` | Написание, отладка и выполнение PowerShell скриптов. Самообучающийся — запоминает предпочтения по стилю |

## Установка

Скопируй содержимое в глобальную папку Claude Code:

```powershell
# Скиллы
Copy-Item -Recurse skills\* "$env:USERPROFILE\.claude\skills\"

# Агенты
Copy-Item agents\*.md "$env:USERPROFILE\.claude\agents\"
```

## Использование

```
/grill-me       — проработать идею перед стартом
/adversarial-review — найти слабые места в плане
/standup-post   — сформировать дневной отчёт
/runbook        — диагностировать проблему
/scaffold       — создать структуру нового проекта
```

Агенты вызываются автоматически по контексту или явно: `/doc-specialist`, `/powershell-specialist`.
